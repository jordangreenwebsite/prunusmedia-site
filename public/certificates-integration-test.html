Web developer handover
A public site ID is not an API secret. The owner approves the website and controls publication. A separate server-only developer bearer key is optional for reading or editing drafts; it must never be pasted into public HTML, this form or a browser script.
Custom website: read the public catalogue, render the course cards in your own style, request individual course details, and use the returned booking URL. The API currently returns one next bookable or waitlist session per course, not a complete timetable.
Test: publish one fictional course, publish multiple courses, change course content/date/price, refresh, then test full courses, waiting lists, disabled publication and no available dates. Example bookings on this page are simulated and do not submit anything.
