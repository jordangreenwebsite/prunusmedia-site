# SEO command centre — Phase 3
Extends the existing business > SEO command centre. Additive D1 migration 0012. No extra paid API or credentials. Agency-only; no website edits, client mail or blog publishing.

## Technical audits
Manual check and per-business opt-in weekly automation. Dedicated six-hour cron processes up to one due audit and one report per run; ideal capacity 28 audits/week, with delayed checks if capacity or network limits are reached. The crawler requests the registered public HTTPS domain only, including www variant, checks robots.txt conservatively, default sitemap (one child sitemap maximum), and samples the homepage plus up to three page candidates and four linked destinations. Bounded response size, timeout, no query-bearing URLs, protected paths (including concept-websites), external redirects, cookies or credentials. Rotates page samples. It does not render JavaScript, confirm indexation, measure Core Web Vitals, or cover every page. 404/410 are confirmed HTTP responses; errors, redirects and blocked checks are not broken-link proof. Multiple H1s, non-self canonicals and noindex are review flags, not necessarily mistakes. Respect site permissions and review network security before enabling production crawls.

## Page mapping and actions
Existing Search Console sync additionally requests up to 1,000 query/page rows (URLs above 900 characters are omitted to keep storage bounded) from the current 28-day finalised period. Suggestions reflect observed impressions; Google omits anonymised and other queries, so missing evidence is not zero. An overlapping query requires at least 10 impressions on the leading page and 5 on a second page, with the second at least 20% as many as the leading page. This is possible cannibalisation, not proof. Other candidates: 20+ impressions and average position 4–20, a 35%+ impression decline from at least 25 prior impressions, observed informational questions with 10+ impressions, sampled technical flags and confirmed broken links. Save mapping only by explicit click. Mark recommendations complete, dismissed or reopened; prior decisions are retained. Blog suggestions use existing editorial idea creation; the editorial quality and approval workflow stays intact.

## Monthly report drafts
Manual generation or per-business opt-in automatic generation of the preceding calendar month (after four-day lag). Finalised GSC aggregate queried for the exact two months; no data is explicitly shown as missing. Reports also include latest saved independent rank observations within month, current outreach record statuses, published blog records last updated in period, completed tasks, most recent audit and current next priorities. These are not historical outreach events or verified publication dates. Reports are saved, viewable, copyable and downloadable as plain text. Manual review and delivery only. No report data exposed to client logins. Historical report regenerations overwrite the saved month. GSC failures produce partial reports; retry manual or opt-in scheduler after a week.

## Release gates
Run the portal CI/security tests and Worker dry-run, review migration and existing production credentials. Test real sign-in and tenant isolation, authorised GSC query/page and monthly data, and audit an authorised public site. Inspect the four cron triggers after deploy. No DataForSEO usage is required by Phase 3.
