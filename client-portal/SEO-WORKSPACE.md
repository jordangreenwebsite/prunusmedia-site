# SEO command centre: Phase 1
Existing portal, existing client/site records, existing D1 and Search Console credentials. Agency-only. No DataForSEO, paid provider, or new credentials required. Migration 0010 is additive. UI lives under each business > SEO command centre.

- Add/edit/remove up to 1,000 saved keywords per client, import 200 per request (one per line or first CSV column), add service/location/registered target page. This is a keyword list, not an independent rank tracker.
- Sync finalised Google Search Console daily totals for the last 28 complete days (ending four days ago) and up to 500 reported queries for each of two periods. Daily totals accumulate in D1 as syncs run; UI shows up to 365 days of saved data. Missing data is not fabricated or treated as zero. Comparisons only for queries returned in both periods.
- Existing Cloudflare daily cron processes up to four due businesses (oldest attempted first); additional businesses rotate across days. Manual sync available. Existing GSC_SERVICE_ACCOUNT_JSON binding and exact property permissions required. Configure via existing protected GitHub production environment PRUNUS_GSC_SERVICE_ACCOUNT_JSON, or coordinate Cloudflare secret management with deployment; do not expose the credential.
- Backlink/outreach registry supports up to 500 records per business, contact/follow-up and notes, opt-in monitoring, manual checks and two due links per daily cron. Checks normal direct anchor links in public HTTPS HTML only. No redirects, authenticated pages, query-bearing source URLs or private IP literals; response cap 1 MB and timeout. Blocked/redirected/JS-only pages are not proof of a lost link. This is not Internet-wide backlink discovery. Do not enter private or signed URLs or confidential contact details.
- No publishing, client-facing metrics, Certificates changes or new automated outreach. Rank checks, search volumes, competitor/backlink discovery and paid API controls belong to Phase 2.
