## The project

A full website rebuild for a roofing and fascias business serving Cirencester, Swindon and the surrounding areas.

The work focused on clear service pages, useful local content, a fast static build and better routes to request a quote. This was the first paying client website completed using the newer Prunus build process. Rankings and enquiry outcomes will only be reported when supported by measurement.
